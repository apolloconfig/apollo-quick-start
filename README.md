`apollo-all-in-one.jar` is stored with [Git LFS](https://git-lfs.com/). Install Git LFS and run `git lfs install` before cloning this repository. For an existing clone, run `git lfs install` followed by `git lfs pull` to download the JAR. The `./demo.sh start` command and Docker usage remain the same.

`apollo-all-in-one.jar` 使用 [Git LFS](https://git-lfs.com/) 存储。克隆仓库前，请安装 Git LFS 并执行 `git lfs install`；已有克隆请执行 `git lfs install` 和 `git lfs pull` 下载 JAR。`./demo.sh start` 命令和 Docker 使用方式不变。
